# AR2v2 加密码解密（→ PCSX2 转换）

## 格式与密钥
- 日站老码 = AR2 v2 (PAR2/GS2v2)：每行两字 = 加密地址 + 加密值。
- **默认密钥 = AR1_SEED = 0x05100518**（多数作品直接用它；`converter.py` 默认）。
- 主码(master) 常见 `EC878304 1434A4A4`：用默认密钥解出 `F01000DC 0022C307` —— 能解出这个 = 密钥正确（PCSX2 一般不需要写入它，仅校验）。
- 少数清单是「キー付き」变体（DEADFACE 机制，行内带新种子）：`find_initial()` 有候选列表；SRW IMPACT 系用不上。

## 解密结果怎么用
- 第 1 个 32 位 = 完整 PCSX2 地址：最高 nibble = 类型（0=8bit写 1=16bit 2=32bit 7=位操作 4=多行头 …），其余 = 地址。
- 第 2 个 = 值。直接可得：`patch=1,EE,<第1字8位hex>,extended,<第2字8位hex>`。
- 例: `3C6CC12C 1456E7A6` → `00FD3E04 00000001`。
- **多行码（类型 4/A/7 等）转换语义未完全验证 → 不轻易交付**（IMPACT 的 SP/换装码即因此搁置）。

## 值族（原码值 → 写入字节）
- 1456E7A5→00, E7A6→01(通用), E7A7→02, E7A8→03, E7A9→1C, E7AC→1F, E7A1→04, E7C5→20, E7CC→3F, E7D6→31 …（非线性，以实测解密为准）。
- 「按部换值」: 1部=E7A8(03) / 2部=E7AC(1F) / 3部=E7A1(04)。

## 算法实现
- `scripts/converter.py`：移植自 pyriell/omniconvert 的 ar2.c（4×32 解密表 + 8 种变换类型）；API：`AR2(key).dec_pair(w1,w2)`、`ar2encrypt()` 反推（往返校验用）。
- 全部输出自动做 RT（round-trip）校验：解密→重加密 ≠ 原码 = 有误。

## 铁证（复用时先跑一遍）
1. `EC878304 1434A4A4` → `F01000DC 0022C307`（主码）。
2. `1CB46B60 17E9C729` → `2025E838 05F5E09C`（资金；与中文圈 PCSX2 原码一字不差）。

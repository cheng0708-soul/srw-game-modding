## 关键机制（IMPACT 系特有）
### 存在标志
- 机体: 记录区自 0x00FD0000 起，记录间隔 0x100，**记录+4 写 1 = 该机可用**；机师: 0x00FF0000 起，+8 写 1。
- 加密码形态 `3C6Cxx2C`（机体系）/ `3C6Axxxx`（机师系），解密后直接就是完整地址。
### 加密字节→记录号公式（仅 IMPACT 系已验证，别跨作套用）
```
偶数字节 X: rec = (X - 0x81) & 0xFF  ←（2026-10-11 校正：旧版误记 −0x82）
奇数字节 X: rec = (X - 0x83) & 0xFF
FD地址 = 0x00FD0004 + rec*0x100
例: BF2C→FD3C04(ガンダム), C12C→FD3E04(BG-3), C02C→FD3F04(シャアザク), D52C→FD5204(ギャプランMS)
```
### 值族（原码值 → 实际写入）
1456E7A5→00, E7A6→01(通用), E7A7→02, E7A8→03, E7A9→1C, E7AC→1F, E7A1→04 …
「1部→E7A8 / 2部→E7AC / 3部→E7A1」（按部换值，用于 Hi-ν / サザビー 等）。
**2026-10-11 实锤**：按部换值 = 按"当前所在部"（不是机体归属部）；第2部里写 01 的机体"出不来"（用户实测：G-3 标志=01 在位仍不出），要改 `1F` 重新加入；第1部加的机体进第2部会被清退（日站实测）。机师同规则（マスターアジア 第2部=AC）。例外: νHWS 第2部=E7A0。
- **跨部行为（日站总结）**: 第1部用码叫出的机体 → 第2部被清退（用第2部版重叫；或第3部复活）；第2部叫出的 → 可带到第3部；进第3部仍可能被「分岐抹消」→ 这就是「按部版」结构的由来。**2026-10-11 用户实测（关键）**：清退仅 = 存在标记失效，机体数据保留——第1部用码加入并改造过的 G-3（强化/配件/机师齐全）进第2部被清退后，用第2部值重叫 → **完整恢复**（「白改造」担忧解除）。未使用过的机体重叫 = 空机体（量产型大魔神实例）。
